# Regeln für dieses Repo (Pflege LF 5 Lernseite)

- Lies zuerst `HANDOVER.md`.
- **Nach jeder Änderung `HANDOVER.md` aktualisieren** (Abschnitte „Was ist fertig / Was fehlt", „Bekannte Probleme" und „Änderungsprotokoll" mit Datum) – im selben Commit. Das hat Hasan ausdrücklich verlangt.
- Inhalte nur in `content/*.txt` ändern, dann `python3 build.py`; `public/index.html` nie von Hand bearbeiten.
- Deutscher Originaltext bleibt wörtlich wie im Arbeitsblatt; Fehler werden nicht im Text korrigiert, sondern mit einer `fix:`-Box darunter.
- Hasan antwortet man auf Arabisch, kurz und direkt.
